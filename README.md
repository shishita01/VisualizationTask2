# Video Game Sales Data Visualization (Tableau)

## Project Overview
This project focuses on visualizing video game sales data using Tableau. The objective is to analyze global sales trends, popular genres, platforms, publishers, and yearly sales patterns through interactive dashboards and charts.



---

##  Dataset Information
- Dataset Name: Video Game Sales
- File Name: vgsales.csv
- Format: CSV
- Records: 11,493 games
- Time Range: 1982 – 2017

### Key Columns Used:
- Name
- Platform
- Year
- Genre
- Publisher
- Global Sales

---

## Tools & Technologies
- Tableau
- CSV Dataset
- GitHub (for version control)

---

## Visualizations Created

### Total Sales by Genre
- Bar chart showing global sales distribution across different game genres.
- Helps identify the most popular genres in terms of sales.

### Sales by Year and Genre
- Area chart representing sales trends over time.
- Includes interactive **Start Year** and **End Year** filters.

###  Top 10 Games by Global Sales
- Horizontal bar chart showing the best-selling video games of all time.

### Top 10 Publishers by Sales
- Bubble chart comparing publishers based on total global sales.

### Top Platforms by Sales
- Treemap visualization showing platform-wise contribution to total sales.

### KPI Indicators
- Total Games in Dataset
- Total Platforms
- Total Publishers

---

## Key Insights
- Action and Sports genres dominate global sales.
- Sales peaked during the mid-2000s to early-2010s.
- Platforms like X360, Wii, and PS3 contributed the highest sales.
- Publishers such as Nintendo and major console publishers lead the market.
